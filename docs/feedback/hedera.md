# Hedera

> Requirement quotes on this page were read from the published prize page on 2026-09-05; that day's saved copy is kept privately with its hash. Where an older fetch is carried forward, the file says so.


**Touches UNICA today:** nothing in the tree. One idea was considered and set aside: an
x402-gated service exposing settlement receipts, settled through a Hedera facilitator.

**Published requirement** (AI & Agentic Payments on Hedera,
ethglobal.com/events/ethonline2026/prizes, retrieved 2026-09-05): "Host a live x402-gated
service on Hedera testnet or mainnet, settled through Blocky402 facilitator."

**What would have to be built:** a separate microservice, a facilitator integration, and a
paying agent — a distinct system with no Uniswap surface involved at any point. This is a
pivot away from the settlement core this project is built around, not an extension of it, which
is why it was not pursued. Nothing toward it exists.

**What we'd ask Hedera to change:** no request. Nothing encountered while scoping this idea
pointed at a documentation or interface gap; it was set aside on fit, not on a defect.

Status: no claim of qualification.
