# V2 — OUTLINE, INCOMPLETE

**This file is an outline, not a specification.** Every heading below is empty. Nothing here has
been decided, reviewed or verified, and this file is not evidence of completed design work.

**V2 design work is in progress. No V2 implementation or deployment exists.**

The live release accepts native input and pays USDC on Ethereum Sepolia. That is
`docs/versions/V1.md`, it is the only version of UNICA that exists, and it does not change.

Why this file is kept in its empty state rather than deleted: an outline that says it is empty
is honest, and a deleted file would hide that the work is unfinished. It is replaced by a
canonical specification only when each heading names the evidence it rests on. Until then, do
not cite this file as a design document, and do not describe V2 as designed, specified,
implementation-ready or audited.

The two documents below ARE real, are long, and open by saying they are not implemented. They
are the substance that exists today, and they are what should be read instead of this outline:

- `docs/INPUT-POLICY-SPEC.md` — the generic ERC-20 payer-input policy
- `docs/PAYOUT-POLICY-SPEC.md` — the immutable payout-asset policy and its red-test matrix
